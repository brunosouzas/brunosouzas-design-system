# Security policy

## Reporting a vulnerability

Please report security issues privately through GitHub's [private vulnerability reporting](https://github.com/brunosouzas/brunosouzas-design-system/security/advisories/new). Do not open a public issue.

You can expect an answer within seven days. This is a one-person project, so a fix may take longer; you will be told the plan.

## Scope

The repository holds design tokens, React components and render scripts. It has no server, stores no data and sends no telemetry. Relevant reports are, for example: a dependency with a known vulnerability that the build or render path actually uses, a script that writes outside its output folder, or a secret committed by mistake.
